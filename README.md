# Possessed Receipt Printer

Original AI-assisted Rive CLI/RML vector animation. A friendly ghost rises from a receipt printer.

This repository is a public preview, **not a contest submission or claim of earnings**.

## What is here
- `scene.rml`: original no-script RML source.
- `scene.riv`: genuine compiled Rive asset.
- `index.html` + `preview.js`: live Rive runtime preview with play/pause/replay and reduced-motion support.
- `walkthrough.mp4`:32-second edited walkthrough of actual source, recorded verification/build JSON and genuine rendered frames; not footage of the original creation session.
- `runtime/`: pinned Rive canvas-lite2.44.0 JS/WASM runtime, MIT notice and provenance.

Original art/source are not licensed for reuse by this preview; no license grant is implied. The separately attributed third-party Rive runtime is MIT-licensed.

## Limits
Automatic animation loop, not a pointer-interactive game. No GPU Canvas or human Editor refinement claimed. Contest eligibility/payout rules and social/entry approval remain separate. No private credentials, native binaries or user email content included.

Official runtime documentation: https://rive.app/docs/runtimes/web/web-js
