Possessed Receipt Printer

A familiar checkout receipt becomes a friendly ghost. A four-second vector loop gives a little printer a Halloween problem.

Built with AI assistance using Rive CLI, RML, keyframed vector animation and a state machine. No external artwork, scripts or GPU Canvas effects.

The controls play, pause and restart the animation. This is not a pointer-interactive game, and no contest prize or paid-client result is claimed.
